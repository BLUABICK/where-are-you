# Алёна: отдельные спрайты с исправленным лицом

Активный набор — `assets/sprites/characters/alyona/poses_hd/`: 12 отдельных PNG 1024×1536 с прозрачным фоном. Спрайты созданы встроенным imagegen по одному, без нарезки и уменьшения из общего листа. Форма открытых глаз и согласованный взгляд взяты с единого исправленного портрета (поза 04). Остальные позы сохраняют это лицо и нейтральную мягкую улыбку; эмоции пока не отдельная система.

Сцена `scenes/novel/artem_test.tscn` загружает для Алёны `poses_hd`, а для Артёма прежний `poses`. Масштаб задаёт общий прямоугольник отображения. Старые спрайты и листы Алёны сохранены для сравнения. Скрипт нарезки старых листов не применяется к HD-набору.

Проверка `--artem-verify` ожидает для Алёны 1024×1536, для Артёма 360×520. Промпты и происхождение изображений — `assets/sprites/characters/alyona/poses_hd/prompts.json`.
