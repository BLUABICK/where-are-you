# Вы где?

Визуальная новелла о компании друзей в Калининграде.

## Запуск
Открыть godot/project.godot в Godot 4.7 и нажать F5. Dialogic включён в проект. Текущая главная сцена — единая лаборатория `godot/tests/sprite_lab.tscn`: пять персонажей, по 12 поз, все готовые фоны и диалоги-заглушки. Это не готовая сюжетная игра. F5 запускает её; для F6 открой эту сцену.

## Материалы
- godot/ — копия основного Godot-проекта с рабочего стола.
- assets/ — исходные и подготовленные изображения персонажей и окружения.
- notes/ — документы проекта; notes/story/writer_only содержит спойлеры.
- tools/ — инструменты подготовки спрайтов.

Кэш Godot, временные файлы, сборки и дубли проверочных проектов исключены из Git.
