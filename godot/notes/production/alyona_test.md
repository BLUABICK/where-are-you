# Алёна — тест спрайтов

В сцене `scenes/novel/artem_test.tscn` добавлен выбор Артёма / Алёны. По умолчанию показана Алёна. Для запуска — F5, для отдельной сцены — F6. Все 12 поз и три фона доступны для каждого персонажа. Кнопка Dialogic запускает соответствующий тестовый сценарий. Реплики временные, не утверждённый сюжет.

Лицо и волосы основаны на фотографиях пользователя: светлые волнистые волосы с прядями у лица, светлые глаза. Одежда: тёмно-синяя расстёгнутая спортивная кофта со светлыми полосками на рукавах, чёрный топ, свободные синие джинсы с тигром на правом бедре.

Лист и промпт: `assets/sprites/characters/alyona/alyona_12_poses.png`, `alyona_12_poses_prompt.txt`. Отдельные прозрачные PNG: подпапка `poses/`, 360×520. Лист создан встроенным imagegen. Нарезка по силуэтам, нормализация размера с nearest-фильтрацией: `tools/split_artem.ps1 -CharacterId alyona -SheetFile alyona_12_poses.png`.

Проверка всех ресурсов: `--headless --path PROJECT -- --artem-verify`. Выбор героя при запуске: `--character=alyona` или `--character=artem`. Проверка диалога: `--artem-dialogue-check`. Снимок: `--artem-capture`, путь `temp/previews/artem_test.png`.
