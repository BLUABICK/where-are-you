# Тестовая сцена Артёма

Открыть `scenes/novel/artem_test.tscn` и нажать F6. Сцена также назначается стартовой для F5 при установке, если главной сцены ещё нет.

- 12 кнопок выбирают позу; стрелки влево/вправо листают их по кругу, 1–9 выбирают первые девять.
- Список фонов: Нижнее озеро, торговый центр, Балтийское море.
- «Проверить диалог Dialogic 2» запускает три тестовые реплики; продолжение — ЛКМ, Enter или пробел. После окончания снова появляется панель текста.
- Реплики — временный текст для проверки, не утверждённый сюжет.

Спрайты: `assets/sprites/characters/artem/poses/`, 12 PNG RGBA, каждый 360×520. Каждый персонаж выделяется по связному силуэту, а не равным ячейкам: жесты могут заходить за границы сетки исходного листа. Центрирование по голове, общий масштаб и высота строки. Границы холста проверяются при извлечении: обрезание силуэта вызывает ошибку. Неоновые пиксели артефактов убраны из отдельных PNG, оригинал сохранён.

Скрипт сцены: `scripts/novel/artem_test.gd`. Сценарий Dialogic: `dialogue/timelines/prologue/artem_test.dtl`. Сам Dialogic не изменён. Персонаж отображается сценой, тестовый таймлайн проверяет вывод текста без отдельного `.dch`.

Актуальный лист: `assets/sprites/characters/artem/artem_12_poses_tracksuit_black_jeans.png`. Олимпийка серая с красными и чёрными панелями по новым фото, чёрные джинсы свободного кроя, более широкие плечи и крепкий торс. Предыдущий исходный лист `artem_12_poses.png` сохранён отдельно. Повторная нарезка: `tools/split_artem.ps1` (PowerShell, System.Drawing). Рисовка создана встроенным imagegen по предоставленным пользователем фотографиям и фону `lower_lake.png`; полный промпт хранится рядом с листом.

Проверка загрузки ресурсов: Godot `--headless --path PROJECT -- --artem-verify`.
Проверка диалога: Godot `--headless --path PROJECT -- --artem-dialogue-check`.
Снимок сцены: Godot `--path PROJECT -- --artem-capture`, результат `temp/previews/artem_test.png`.
Для выбора позы при запуске: `--artem-pose=12` (номер 1–12); можно сочетать со снимком.
