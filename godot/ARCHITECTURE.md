# Структура визуальной новеллы

Имена папок и файлов — на английском в `snake_case`, текст игры и заметки можно писать на русском. В игровых ресурсах используем пути `res://…`.

## Материалы для разработки

Эти папки содержат `.gdignore`: Godot не импортирует их содержимое и не показывает его в панели ресурсов. Открывай их обычным редактором или файловым менеджером.

| Папка | Содержимое |
| --- | --- |
| `source_assets/art/` | Исходники рисунков, слои, большие оригиналы |
| `source_assets/audio/` | Исходные записи и проекты аудиоредактора |
| `source_assets/fonts/` | Исходные архивы и материалы шрифтов |
| `source_assets/video/` | Исходное видео и проекты монтажа |
| `temp/incoming/` | Файлы, которые ещё нужно разобрать |
| `temp/conversion/input/` | Копии файлов перед конвертацией |
| `temp/conversion/output/` | Результат конвертации перед проверкой |
| `temp/previews/` | Пробные изображения, рендеры и превью |
| `temp/logs/` | Новые журналы запусков и конвертации |
| `notes/story/` | Общий синопсис, хронология и сюжетные Markdown-заметки |
| `notes/story/chapters/` | Черновики и планы глав |
| `notes/story/characters/` | Биографии, мотивация и отношения персонажей |
| `notes/story/world/` | Лор, места, правила мира |
| `notes/story/branches/` | Развилки, условия, концовки |
| `notes/design/` | Механики, интерфейс, художественное направление |
| `notes/production/` | Задачи, списки нужных ассетов, рабочие заметки |
| `tools/conversion/` | Скрипты для обработки и конвертации материалов вне Godot |
| `builds/` | Экспортированные сборки |

`source_assets/` и `notes/` предназначены для постоянного хранения. Содержимое `temp/` и `builds/` исключено из Git, кроме маркеров структуры. Единственные экземпляры важных файлов в `temp/` не храним. `.gitkeep` сохраняет пустые папки в Git.

## Как раскладывать новые материалы

1. Постоянный оригинал положить в `source_assets/`.
2. Рабочую копию для обработки — в `temp/conversion/input/`, результат — в `temp/conversion/output/`.
3. Проверенный игровой файл перенести в соответствующую папку `assets/` и подключить в Godot или Dialogic. Рядом с приобретёнными материалами сохранять лицензии и сведения об источнике.
4. Идеи и черновой текст писать в `notes/story/`, исполняемые диалоги собирать в `dialogue/timelines/`.

Например: `assets/sprites/characters/anna/anna_happy.png`, `dialogue/characters/anna.dch`, `dialogue/timelines/chapters/chapter_01/arrival.dtl`, `notes/story/characters/anna.md`.

Папки сами по себе не добавляют игровые сцены, Autoload или сценарии. Существующие файлы плагина и теста оставлены на прежних путях.
